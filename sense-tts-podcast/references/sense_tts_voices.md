# SenseAudio（商汤）音色列表与播客场景推荐

> 💡 **使用建议**：根据播客主题选择合适的音色组合，避免音色风格与内容严重不匹配。
> 所有音色均为**中文普通话**（SenseAudio 官方精品音色库无英文/方言音色；英文单词会以中文口音朗读，脚本中英文缩写务必给出中文读法，见 prompts/podcast_script.md 的"TTS 口播友好"规则）。

---

## ⚠️ 套餐分级与可用性（重要）

音色分四级：**普通（Free）→ VIP（Plus）→ SVIP（Pro/Max/Ultra）→ 独家定制**。
`/v1/get_voice` 返回的是账号**可见**的音色，**不等于可合成**——用超出套餐的音色会返回
`403 no access to the specified voice`，tts.py 会明确报错并中止。

> ⚠️ **"限免使用" ≠ API 权限**：官网控制台（platform.senseaudio.cn）语音应用里很多 SVIP
> 音色标着"限免使用"，网页试听可用；但那是网页登录态通道，**开放 API（本技能使用的
> `api.senseaudio.cn/v1/t2a_v2`）不享受限免**，超套餐音色照样 403（2026-09 实测）。
> 官方文档也注明"套餐范围不含限免音色和自定义音色"。要在 API 里用 SVIP 音色只能升级套餐。

| 套餐 | 可用角色 |
|------|---------|
| **Free（实名认证默认）** | 儒雅道长、沙哑青年、可爱萌娃 |

## 🌐 网页版通道（web_tts.py）：74 角色 / 167 标签

`scripts/web_tts.py` 走 senseaudio.cn 网页控制台的未公开接口
（`platform.senseaudio.cn/api/voice/tts`，需 `SENSE_WEB_TOKEN` 登录态令牌），
**不受 API 套餐限制**：74 个角色（比 API 多一倍）、33 个角色处于"限免"状态
（含全部 SVIP），限免期间通常免费。代价：token 约 60 天过期、重新登录即轮换、
接口无文档可能变化。运行 `python scripts/web_tts.py --check` 查看当前完整列表。
